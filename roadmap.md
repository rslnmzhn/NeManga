# 🗺️ NeManga — Дорожная карта развития (Roadmap)

> **Статус:** отметки в разделах 1–5 отражают ранее добавленные реализации, а не полную проверку всех сценариев. Они не означают 100% готовность. Ниже, в разделе 6, зафиксированы необходимые исправления, доведение функций до исходных требований и новые возможности. Все новые пункты пока запланированы.

Стратегический план развития и улучшения полностью автономного и легковесного оффлайн-ридера манги **NeManga** для Android. Все функции работают строго локально на устройстве, без сторонних серверов, облаков и внешних API.

---

## 1. 🚀 Ридер (Reader Experience)
> Оптимизация процесса чтения, где пользователь проводит 90% времени.

- [x] **Бесшовный переход между главами (Seamless Chapter Transition)**
  - По достижении последней страницы главы — появление карточки-триггера: *«Глава завершена! Потяните вверх / свайпните, чтобы открыть Главу N+1»*.
  - Автоматическая предзагрузка и переход к следующей главе без выхода в меню.
- [x] **Перелистывание кнопками громкости (Volume Keys Navigation)**
  - Навигация одной рукой: качелька «вниз» — следующая страница (или скролл вебтуна на высоту экрана), «вверх» — предыдущая страница.
  - Настраиваемый тумблер включения/выключения в настройках ридера.
- [x] **Тактильный виброотклик (Haptic Feedback)**
  - Мягкий тактильный щелчок при перелистывании страниц, слайдере, переходе между главами и переключении тумблеров.
- [x] **Сетка всех страниц (Thumbnail Grid / Быстрый скраббер)**
  - Кнопка в меню ридера открывает визуальную сетку миниатюр всех страниц текущей главы.
  - Возможность мгновенно найти нужный фрейм и перепрыгнуть на него в один тап.
- [x] **Двустраничный режим (Dual Page Spreads)**
  - Отображение двух страниц рядом в альбомной ориентации или на планшетах (с сохранением порядка RTL для манги).
- [x] **Глубокий ночной режим с кастомным фильтром яркости**
  - Ползунок затемнения внутри ридера, позволяющий сделать экран темнее минимальной системной яркости Android (0%..80%).
  - Опциональный тёплый оттенок (сепия) для комфортного чтения в полной темноте.
- [x] **Умный сплит двойных страниц (Auto-split double page spreads)**
  - Автоматическое распознавание ландшафтных разворотов (`width > height`).
  - Виртуальное разделение разворота на две вертикальные страницы с сохранением направления чтения (RTL для манги, LTR для манхвы/комиксов) без необходимости ручного приближения.
- [x] **Автоматическая обрезка полей (Smart Margin Crop)**
  - Алгоритмическая обрезка пустых белых/чёрных технических полос по краям сканов для максимального заполнения полезной площади экрана.
- [x] **Автопрокрутка для Вебтунов (Auto-scroll)**
  - Плавная автоматическая вертикальная прокрутка длинных глав с регулировкой скорости (`0.5x .. 6.0x`) и паузой для непрерывного чтения без постоянных свайпов.
- [x] **Закладки и галерея любимых кадров (Bookmarks & Snapshots)**
  - Локальное сохранение любимых страниц в закладки тайтла и возможность быстрого экспорта текущего кадра в Загрузки/NeManga/Snapshots в память устройства.

## 2. ⚡ Мощь работы с файлами, памятью и каталогизацией (Storage & Library)
> Скорость, автономность, порядок и контроль над дисковым пространством.

- [x] **Сжатие в WebP с выбором пресетов и удалением оригиналов**
  - Экономия до 60–80% дискового пространства устройства без потери читаемости диалогов.
- [x] **Автосканирование папки `Download/NeManga`**
  - Кнопка *«Синхронизировать папку»* на главном экране.
  - Автоматическое обнаружение новых архивов `.zip` и `.cbz`, скачанных через браузер или перенесённых с ПК, и их добавление в библиотеку с группировкой по главам.
- [x] **Дашборд сэкономленной памяти (Storage Dashboard)**
  - Информационный блок в меню приложения:
    *Количество сжатых глав, общий объём, текущий размер и суммарно освобождённое место на устройстве.*
- [x] **Локальное резервное копирование и экспорт (Backup & Restore)**
  - Экспорт всей базы данных (прогресс чтения, статусы «Читаю/Прочитано», теги и настройки) в лёгкий `.json` файл в папку Загрузок устройства.
  - Восстановление библиотеки в один клик из локального JSON-файла.
- [x] **Каталог авторов и схема `[Группа (Автор)]`**
  - Автоматическое распознавание авторов из скобок в названии, обложка автора из последнего архива, теги авторов.
  - Ручная привязка и отвязка манги от авторов в просторном окне с предпросмотром страниц.
- [x] **Блэклист мусорных префиксов и сайтов с шаблонами `*`**
  - Исключение сайтов и команд сканлейта из списка авторов по маскам `author-*`, `site*` и др.
- [x] **Массовое переименование и очистка названий архивов**
  - Очистка названий тайтлов от сайтов и технических номеров с обязательным предпросмотром на 3 мангах перед применением.
- [x] **Автоматическая очистка мусора из блэклиста при импорте новой манги**
  - При сканировании или добавлении архивов все мусорные префиксы сайтов из блэклиста шаблонов автоматически отсекаются от названий тайтлов и глав.
- [x] **Кастомный выбор обложки тайтла**
  - Возможность выбрать любую страницу из любого тома архива или локальную картинку из галереи вместо первой попавшейся рекламы в архиве.
- [x] **Поддержка локальных метаданных `ComicInfo.xml`**
  - Автоматическое считывание информации о манге (автор, аннотация, год, переводчики, издатель) из стандартного XML внутри архивов CBZ/ZIP при добавлении в библиотеку.
- [x] **Пользовательские полки и категории (Custom Shelves / Collections)**
  - Создание собственных категорий и полок («Любимое», «Шедевры», «Короткие синглы», «На перечитку») помимо базовых статусов чтения с фильтрацией на главном экране.
- [x] **Локальный поиск и дедупликация дубликатов архивов (Duplicate Finder)**
  - Обнаружение повторно скачанных глав в разных форматах или разном разрешении для быстрого удаления дубликатов и освобождения памяти устройства.

## 3. 🎨 Визуал, интерфейс и персонализация (UI/UX)
> Эстетика аниме, адаптивность и удобство.

- [x] **Режим True AMOLED Black**
  - Глубокий абсолютно чёрный цвет (`#000000`) для фона ридера и библиотеки. На OLED/AMOLED дисплеях пиксели отключаются, что экономит заряд батареи.
- [x] **Аниме-палитры акцентных цветов**
  - 🌸 **Sakura Pink** (в тон чиби неко-тян с иконки);
  - 💜 **Cyberpunk Violet** (неоновый фиолетовый);
  - 🍃 **Neon Mint** (мятно-бирюзовый);
  - ☀️ **Sunburst Amber** (тёплый янтарный);
  - ⚡ **Electric Blue** (насыщенный синий).
- [x] **Гибкая сортировка библиотеки**
  - По времени последнего чтения (сверху то, что читается прямо сейчас);
  - По алфавиту (А–Я / A–Z);
  - По общему прогрессу прочтения;
  - По автору.
- [x] **Интерактивный счётчик манги (Штуки ⇄ Место на диске)**
  - Тап по количеству тайтлов в шапке переключает отображение на общий объём в МБ/ГБ.
- [x] **Кнопка фильтров по статусам чтения и полкам**
  - Компактный диалог со статусами («Читаю / В планах / Прочитано») и пользовательскими полками рядом с сортировкой.
- [x] **Анимированный сплэш-скрин**
  - Плавный запуск приложения с маскотом неко-тян при старте.

## 4. ⚡ Скорость, движок и оптимизация (Engine & Cache)
> Производительность на тяжелых архивах и мгновенный отклик.

- [x] **Упреждающая предзагрузка страниц (Predictive Preloader)**
  - Фоновый кэш следующих 3–5 страниц в память в фоновом режиме для мгновенного отклика без малейших задержек при перелистывании.
- [x] **Аппаратное ускорение декодирования изображений (Cache Constraints)**
  - Ограничение разрешения декодирования тяжелых WebP и PNG в память устройства (`cacheWidth` под Retina-разрешение экрана), экономящее до 70% RAM и устраняющее лаги.

## 6. Следующий этап: надёжность и развитие локального ридера

Все пункты ниже — запланированные работы, не реализованные функции. Данные остаются на устройстве; облака, аккаунты и внешние трекеры не требуются.

### 6.1. Приоритет P0 — исправления и сохранность коллекции

- [x] **Согласованная навигация после разделения разворотов**
  - Разделить индекс страницы архива и индекс отображаемой половины; сохранять страницу и половину разворота.
  - Проверить восстановление позиции, RTL/LTR, слайдер, миниатюры, кнопки громкости и смену режимов без пропусков половин.
- [ ] **Настоящая обрезка пустых полей вместо фиксированного увеличения на 7%**
  - Анализировать края изображения и обрезать только подтверждённые пустые белые/чёрные области.
  - Ограничивать глубину обрезки, сохранять текст и рисунок, разрешить отключение для отдельной страницы; оригинал не изменять.
- [x] **Безопасное обнаружение и удаление дубликатов**
  - Различать точные дубли (проверка содержимого/хешей) и предположительно похожие главы; совпадение названия не считать доказательством.
  - Показывать обе обложки, полные пути, размеры и число страниц перед подтверждением удаления.
  - Проверять использование файла другими тайтлами; менять записи только после успешной файловой операции, явно показывать ошибки.
- [x] **Закладки с адресом «тайтл → глава → страница → половина»**
  - Не смешивать одинаковые номера страниц разных глав; предусмотреть совместимость со старыми закладками.
  - Отдельная галерея закладок с миниатюрами и переходом к сохранённому месту.
- [ ] **Достоверная статистика чтения**
  - Приостанавливать время при сворачивании и блокировке; предзагрузку не считать чтением.
  - Различать просмотры и уникальные страницы; корректно учитывать завершённые главы.
  - Дневные, недельные и месячные отчёты, любимые жанры и авторы, без сети.
- [x] **Единая очистка названий во всех путях импорта**
  - Проверить одиночный и пакетный импорт, сканирование папки и добавление глав в существующий тайтл.
  - Разделить изменение отображаемого названия и реальное переименование файла; сохранять расширения, пути, прогресс и связи, проверять конфликты имён.
  - Предпросмотр полных изменений на трёх подходящих мангах (или всех, если их меньше), подтверждение и отмена массовой операции.
- [x] **Выбор обложки из любой главы, а не только первой**
  - Выбор главы → сетка страниц → подтверждение обложки; сохранить также выбор локального изображения.
- [ ] **Проверяемая оптимизация памяти вместо обещаний аппаратного ускорения**
  - Учитывать реальную плотность экрана, масштабирование и длинные вебтуны; согласовать ключи предзагрузки и отображения.
  - Измерить память и плавность на тяжёлых архивах; не обещать устранение всех OOM или фиксированный процент экономии без замеров.

### 6.2. Приоритет P1 — пакетная работа и структура библиотеки

- [x] **Пакетное выделение тайтлов долгим нажатием**
  - Назначать автора, добавлять/удалять жанры и полки, менять статус, сжимать выбранные архивы.
  - Объединять тайтлы, переносить главы; отдельно выбирать удаление из библиотеки или вместе с файлами.
  - Показывать количество выбранных объектов, последствия и результат операции, сохранять прогресс.
- [x] **Редактор структуры манги**
  - Перетаскивание глав, ручные номера томов/глав, перенос между тайтлами.
  - Разделение ошибочно объединённого тайтла и объединение записей без повторного импорта.
  - Предупреждения о возможных пропусках глав (1, 2, 4) без автоматического удаления или перенумерации.

### 6.3. Приоритет P2 — персональные настройки и локальный бэкап

- [ ] **Настройки отдельно для каждого тайтла**
  - RTL/LTR/лента, подгонка по ширине/высоте, сплит, обрезка, яркость, тёплый фильтр, скорость автопрокрутки.
  - Кнопка «Использовать общие настройки», предсказуемое наследование и сохранение после перезапуска.
- [x] **Полноценное локальное резервное копирование**
  - Полки и состав, теги авторов, правила очистки и авторский блэклист, закладки, статистика, пользовательские обложки, настройки тайтлов.
  - Версионирование формата, проверка перед записью, выбор «Объединить»/«Заменить» и отчёт об отсутствующих файлах.
  - Проверить восстановление на чистой установке, включая обложки, а не только их старые пути.

### 6.4. Приоритет P3 — диагностика, корзина и поиск

- [x] **Проверка здоровья библиотеки**
  - Обнаруживать отсутствующие/перемещённые архивы, отсутствие доступа, повреждения, отсутствие изображений, потерянные обложки и повторные ссылки.
  - Действие «Указать новое расположение» сохраняет прогресс, автора, теги и закладки.
- [ ] **Локальная корзина и история изменений**
  - Перемещать удаляемые файлы в корзину, если позволяют доступ и свободное место; не подменять ошибку перемещения необратимым удалением.
  - Показывать срок хранения и размер, восстанавливать файл вместе с привязками, подтверждать окончательную очистку.
  - Отмена переименований и смены автора; журнал массовых операций.
- [x] **Расширенный поиск без усложнения обычного ввода**
  - Необязательные команды: `автор:"Имя Автора"`, `жанр:драма`, `полка:любимое`, `статус:непрочитано`, `размер:>500МБ`.
  - Поиск по главам, именам файлов и папкам; исключение жанров; сохранённые запросы, например «Непрочитанные короткие манги».

### 6.5. Приоритет P4 — форматы и повседневные удобства

- [ ] **Дополнительные локальные форматы**
  - Поэтапно: CBR/RAR, 7Z/CB7, папки изображений без упаковки, затем PDF с отдельным механизмом отображения.
  - Для каждого формата проверить лицензии и совместимость библиотек, память, скорость и обработку повреждённых файлов. Новые зависимости согласовывать отдельно.
- [x] **«Продолжить чтение» на главном экране** — возврат к последнему месту одним нажатием.
- [x] **Случайный непрочитанный тайтл** — подбор из локальной коллекции с учётом выбранных фильтров.
- [ ] **Личная оценка и заметка** — впечатления и причина откладывания тайтла.
- [ ] **Настраиваемые зоны нажатия** — удобство чтения одной рукой.
- [ ] **Блокировка ориентации для тайтла** — без случайных поворотов экрана.
- [ ] **Таймер напоминания о перерыве** — локальное уведомление во время долгого чтения.
- [ ] **Очередь фонового сжатия с отменой** — библиотека остаётся доступной; отмена не повреждает исходные архивы.
- [ ] **Размер карточек и режим списка** — удобная навигация по большой коллекции.
- [ ] **Полное название по долгому нажатию** — совместить с пакетным выделением через явное действие в контекстном меню, без конфликта жестов.

### Порядок реализации и критерии готовности

1. P0: навигация, сохранность файлов, закладки, корректность уже выпущенных функций.
2. P1: пакетные действия и редактор глав.
3. P2: настройки тайтлов и полноценное восстановление из локальной копии.
4. P3: диагностика, корзина и поиск.
5. P4: форматы и дополнительные удобства.

Пункт отмечается выполненным только после реализации всех перечисленных сценариев и профильных проверок. Для рискованных операций нужны тесты отмены, ошибок доступа, конфликтов имён и сохранения связей; для интерфейса — проверки небольшого экрана, клавиатуры и жизненного цикла приложения. Успешный CI сам по себе не означает завершение роадмапы.
