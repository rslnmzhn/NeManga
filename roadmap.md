# 🗺️ NeManga — Дорожная карта развития (Roadmap)

Стратегический план развития и улучшения легковесного оффлайн-ридера манги **NeManga** для Android.

---

## 1. 🚀 Киллер-фичи для ридера (Reader Experience)
> Оптимизация процесса чтения, где пользователь проводит 90% времени.

- [ ] **Бесшовный переход между главами (Seamless Chapter Transition)**
  - По достижении последней страницы главы — появление карточки-триггера: *«Глава завершена! Потяните вверх / свайпните, чтобы открыть Главу N+1»*.
  - Автоматическая предзагрузка первой страницы следующей главы для мгновенного перехода без выхода в меню.
- [ ] **Перелистывание кнопками громкости (Volume Keys Navigation)**
  - Навигация одной рукой: качелька «вниз» — следующая страница (или скролл вебтуна на высоту экрана), «вверх» — предыдущая страница.
  - Настраиваемый тумблер включения/выключения в настройках ридера.
- [ ] **Тактильный виброотклик (Haptic Feedback)**
  - Мягкий тактильный щелчок при перелистывании страниц, достижении границ главы и переключении тумблеров.
- [ ] **Сетка всех страниц (Thumbnail Grid / Быстрый скраббер)**
  - Кнопка в меню ридера открывает визуальную сетку миниатюр всех страниц текущей главы.
  - Возможность мгновенно найти нужный фрейм и перепрыгнуть на него в один тап.
- [ ] **Двустраничный режим (Dual Page Spreads)**
  - Отображение двух страниц рядом при повороте устройства в альбомную ориентацию или на планшетах.
  - Опция подгонки первой страницы (обложки) как одиночной страницы.
- [ ] **Глубокий ночной режим с кастомным фильтром яркости**
  - Ползунок затемнения внутри ридера, позволяющий сделать экран темнее минимальной системной яркости Android.
  - Опциональный тёплый оттенок (сепия) для комфортного чтения в полной темноте.

## 2. ⚡ Мощь работы с файлами и памятью (Storage & Library)
> Скорость, автономность и контроль над дисковым пространством.

- [ ] **Автосканирование папки `Download/NeManga`**
  - Кнопка *«Синхронизировать папку»* на главном экране.
  - Автоматическое обнаружение новых архивов `.zip` и `.cbz`, скачанных через браузер или перенесённых с ПК, и их добавление в библиотеку с группировкой по главам.
- [ ] **Дашборд сэкономленной памяти (Storage Dashboard)**
  - Информационный блок в меню или в разделе «О приложении»:
    *Количество сжатых глав, исходный вес, текущий вес и суммарно освобождённое место на устройстве (например, «Сэкономлено 4.8 ГБ»).*
- [ ] **Резервное копирование и экспорт (Backup & Restore)**
  - Экспорт всей базы данных (прогресс чтения, статусы «Читаю/Прочитано», теги и закладки) в лёгкий `.json` файл в папку Загрузок.
  - Восстановление библиотеки в один клик при переустановке приложения или смене смартфона.

## 3. 🎨 Визуал, интерфейс и персонализация (UI/UX)
> Эстетика аниме, адаптивность и удобство.

- [ ] **Режим True AMOLED Black**
  - Глубокий абсолютно чёрный цвет (`#000000`) для фона ридера и библиотеки. На OLED/AMOLED дисплеях пиксели отключаются, что экономит до 25–30% заряда батареи.
- [ ] **Аниме-палитры акцентных цветов**
  - 🌸 **Sakura Pink** (в тон чиби неко-тян с иконки);
  - 💜 **Cyberpunk Violet** (неоновый фиолетовый);
  - 🍃 **Neon Mint** (мятно-бирюзовый);
  - ☀️ **Sunburst Amber** (тёплый янтарный);
  - ⚡ **Electric Blue** (насыщенный синий).
- [ ] **Гибкая сортировка библиотеки**
  - По времени последнего чтения (сверху то, что читается прямо сейчас);
  - По алфавиту (А–Я / A–Z);
  - По общему прогрессу прочтения.
- [ ] **Анимированный сплэш-скрин**
  - Плавный запуск приложения с маскотом неко-тян при холодном старте.
