# 🗺️ NeManga — Дорожная карта развития (Roadmap)

Стратегический план развития и улучшения легковесного оффлайн-ридера манги **NeManga** для Android.

---

## 1. 🚀 Киллер-фичи для ридера (Reader Experience)
> Оптимизация процесса чтения, где пользователь проводит 90% времени.

- [x] **Бесшовный переход между главами (Seamless Chapter Transition)**
  - По достижении последней страницы главы — появление карточки-триггера: *«Глава завершена! Потяните вверх / свайпните, чтобы открыть Главу N+1»*.
  - Автоматическая предзагрузка и переход к следующей главе без выхода в меню.
- [x] **Перелистывание кнопками громкости (Volume Keys Navigation)**
  - Навигация одной рукой: качелька «вниз» — следующая страница (или скролл вебтуна на высоту экрана), «вверх» — предыдущая страница.
  - Настраиваемый тумблер включения/выключения в настройках ридера.
- [x] **Тактильный виброотклик (Haptic Feedback)**
  - Мягкий тактильный щелчок при перелистывании страниц, слайдере, переходе между главами и переключении тумблеров.
- [x] **Сетка всех страниц (Thumbnail Grid / Быстрый скраббер)**
  - Кнопка в меню ридера открывает визуальную сетку миниатюр всех страниц текущей главы.
  - Возможность мгновенно найти нужный фрейм и перепрыгнуть на него в один тап.
- [x] **Двустраничный режим (Dual Page Spreads)**
  - Отображение двух страниц рядом в альбомной ориентации или на планшетах (с сохранением порядка RTL для манги).
- [x] **Глубокий ночной режим с кастомным фильтром яркости**
  - Ползунок затемнения внутри ридера, позволяющий сделать экран темнее минимальной системной яркости Android (0%..80%).
  - Опциональный тёплый оттенок (сепия) для комфортного чтения в полной темноте.

## 2. ⚡ Мощь работы с файлами и памятью (Storage & Library)
> Скорость, автономность и контроль над дисковым пространством.

- [x] **Автосканирование папки `Download/NeManga`**
  - Кнопка *«Синхронизировать папку»* на главном экране.
  - Автоматическое обнаружение новых архивов `.zip` и `.cbz`, скачанных через браузер или перенесённых с ПК, и их добавление в библиотеку с группировкой по главам.
- [x] **Дашборд сэкономленной памяти (Storage Dashboard)**
  - Информационный блок в меню приложения:
    *Количество сжатых глав, общий объём, текущий размер и суммарно освобождённое место на устройстве.*
- [x] **Резервное копирование и экспорт (Backup & Restore)**
  - Экспорт всей базы данных (прогресс чтения, статусы «Читаю/Прочитано», теги и настройки) в лёгкий `.json` файл в папку Загрузок.
  - Восстановление библиотеки в один клик из JSON-файла.

## 3. 🎨 Визуал, интерфейс и персонализация (UI/UX)
> Эстетика аниме, адаптивность и удобство.

- [x] **Режим True AMOLED Black**
  - Глубокий абсолютно чёрный цвет (`#000000`) для фона ридера и библиотеки. На OLED/AMOLED дисплеях пиксели отключаются, что экономит заряд батареи.
- [x] **Аниме-палитры акцентных цветов**
  - 🌸 **Sakura Pink** (в тон чиби неко-тян с иконки);
  - 💜 **Cyberpunk Violet** (неоновый фиолетовый);
  - 🍃 **Neon Mint** (мятно-бирюзовый);
  - ☀️ **Sunburst Amber** (тёплый янтарный);
  - ⚡ **Electric Blue** (насыщенный синий).
- [x] **Гибкая сортировка библиотеки**
  - По времени последнего чтения (сверху то, что читается прямо сейчас);
  - По алфавиту (А–Я / A–Z);
  - По общему прогрессу прочтения.
- [x] **Анимированный сплэш-скрин**
  - Плавный запуск приложения с маскотом неко-тян при старте.
